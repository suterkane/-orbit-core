AUFGABE:
  Erstelle einen SYSTEMCHECK beim Boot: Prüfe dass alle Module laden 
  (Storage, Neural, Voice, Briefing, AI, Dashboard, Weather). Wenn etwas 
  fehlt → Clear-Message zur Fehlerbehebung statt Silent-Fail. Zeige echte 
  Systemstatus: 'Modules: 6/6 ✓', 'Vault: synced', 'Weather: online', etc.

PROBLEM BEHOBEN:
  Silent-Failures sind das echte Problem. Ein Modul lädt nicht? Früher: 
  Stille. Jetzt: Klare, actionable Meldung mit:
  - Fehler-Typ (MODULE_MISSING, STORAGE_WRITE_FAILED, etc.)
  - Severity-Level (critical | high | low)
  - Technische Details
  - Konkrete Lösungsschritte für Rene

API FÜR ANWENDUNGEN
================================================================================

// Manuell Run
window.ORBITSystemCheck.run()
  .then(status => console.log('Boot Status:', status))
  .catch(err => console.error('Check failed:', err))

// Status abrufen (synchron)
const status = window.ORBITSystemCheck.status()
console.log(status.modules)           // Modul-Status
console.log(status.errors)            // Fehler-Array
console.log(status.warnings)          // Warnungs-Array
console.log(status.bootTime)          // ms

// JSON-Export
const json = window.ORBITSystemCheck.details()
// Kann später an Monitoring-System übertragen werden

// Event
document.addEventListener('ORBITSystemCheckComplete', () => {
  console.log('Boot complete!')
})

WARUM DAS WICHTIG IST
================================================================================

VORHER (Silent-Fails):
  - App startet
  - Modul A fehlt → Keine Meldung
  - Feature X funktioniert nicht → Rene fragt sich, warum
  - Debugging → Zeitaufwändig

NACHHER (Transparente Checks):
  - App startet
  - Boot-Check läuft (< 50ms)
  - Modul A fehlt → SOFORT Meldung mit konkreter Lösung
  - Rene kennt Status und nächste Schritte
  - Debugging → Schnell und zielgerichtet
