# ORBIT CORE — Core

## Zweck

Der `core/`-Bereich enthält die zentralen Bausteine von ORBIT.

Hier gehören ausschließlich Komponenten hinein, die für die grundlegende Identität, Regeln oder den zentralen Zustand von ORBIT verantwortlich sind.

## Verantwortungsbereich

- Identität von ORBIT
- zentrale Regeln
- zentraler Zustand
- grundlegende Konfiguration

## Abgrenzung

Missionen, Wissen, technische Integrationen und Benutzeroberflächen gehören nicht direkt in diesen Bereich. Sie werden in ihren jeweils vorgesehenen Architektur-Ebenen aufgebaut.
