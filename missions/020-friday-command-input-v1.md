# Mission 20 · FRIDAY Command Input V1

**Status:** In Arbeit

## Ziel
Die Schnellerfassung versteht einfache deutsche Befehle zuverlässig, ohne externe KI-Abhängigkeit.

## V1 erkennt
- `Aufgabe ...`
- `Idee ...`
- `Gedanke ...` / `Notiz ...`
- `Erinnere mich ...`
- Zeitwörter `heute`, `morgen`, `übermorgen`
- Priorität über `wichtig`, `Priorität`, `Prio`

## Regeln
- Unbekannte Eingaben bleiben normale Gedanken.
- Keine Daten werden verworfen.
- Keine Cloud-KI ist für die Grundfunktion nötig.
- Bestehender ORBIT Sync bleibt unverändert.

## Kontrollpunkt
Mission gilt als bestanden, wenn die Eingabe auf Desktop und iPhone korrekt kategorisiert und terminiert wird.
